# HerbBloom 全草药常开

- 作者: 不是现在
- 适用: TShock 6.x · Terraria 1.4.5.x
- 功能: **所有草药成熟即开花、无视一切开花条件，且开花后永不回退**——把原版
  「霜花（Shiverthorn）成熟后开花且不落」的逻辑推广到全部品种；生长速度默认
  保持原版，可在配置里加速。

## 行为

| 机制 | 说明 |
| --- | --- |
| 开花 | 幼草成熟后立即变为开花态，无视昼夜、天气、月相、深度的原版窗口 |
| 不回退 | 闪光根随机落花、熔岩火焰花水量切换等原版回退，会在下一个巡检周期被自动改回开花态 |
| 采集 | 开花态采集必掉种子（开花 tile 在原版判定里永远"可收种"） |
| 生长 | 默认**完全原版速度**（插件不催熟）；开启加速后仅作用于玩家附近区域 |
| 盆栽 | 陶盆 / 种植架上的草药与地面共用同一套 tile，自动一并生效 |

覆盖品种：太阳花、月光草、闪光根、死亡草、水叶草、火焰花、霜花（Shiverthorn）。

## 配置

文件：`tshock/HerbBloom.json`，首次运行自动生成；**修改后重启服务器生效**（无游戏内指令）。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `启用` | `true` | 总开关；关闭后插件完全不改动草药 |
| `无视条件开花` | `true` | 成熟草药立即变开花态 |
| `开花后不回退` | `true` | 巡检周期内把被回退的草药改回开花态 |
| `幼草直接开花` | `false` | `false`：幼草成熟后才开花（霜花式）；`true`：连幼草也直接开花 |
| `生长速度倍率` | `0` | **默认 0 = 完全原版生长速度**；>0 时按 `生长基础概率 × 倍率` 催熟玩家附近幼草 |
| `生长基础概率` | `0.2` | 每次扫描每株幼草的成熟基础概率（实际 = 基础 × 倍率，上限 1） |
| `扫描间隔秒` | `10.0` | 巡检周期 |
| `玩家扫描半径` | `160` | 玩家周边即时处理半径（格），催熟只作用于该区域 |
| `全局扫描列数` | `600` | 每周期全世界推进扫描的列数（负责远处草药的开花强制） |
| `每刻最大同步数` | `1500` | 每游戏刻最多广播的 tile 数（限流，防止首次全图转换刷包） |
| `详细日志` | `false` | 每轮扫描输出入队/转换统计 |

典型调整示例：

- 农场全即时成熟：`幼草直接开花: true`
- 稍微加速生长：`生长速度倍率: 0.05`（约 17 分钟成熟）、`0.02`（约 42 分钟）

## 实现原理（Terraria 1.4.5）

1. 1.4.5 把草药统一为三个 tile：`82 幼年 / 83 成熟 / 84 开花`，品种 =
   `frameX / 18`（0太阳花 1月光草 2闪光根 3死亡草 4水叶草 5火焰花 6霜花），
   三种状态帧编码相同，状态切换只改 `type`。
2. 原版服务端 `WorldGen.GrowAlch` 只对闪光根做 83↔84 随机开落（1/5 概率回退）、
   对霜花做 83→84（1/30 概率、永不回退）；其余品种的"开花"其实是客户端
   `TileDrawing.IsAlchemyPlantHarvestable(style)` 按昼夜/月相/下雨/时段把成熟草
   **渲染**成开花，条件结束即收拢，采集判定 `IsHarvestableHerbWithSeed` 同样只认窗口。
3. 本插件把成熟草(83)直接改成开花 tile(84)：客户端对 84 无任何条件判断，
   永远渲染开花、采集必掉种子；再由周期巡检把任何被回退的 84→83 改回，等效
   "开花后不再取消开花"。
4. 改动按原版服务端同款方式广播 `NetMessage.SendTileSquare(-1, x, y, 1, TileChangeType.None)`；
   扫描线程只读 tile 收集坐标，主线程泵二次校验（类型/品种/帧合法性）后写入，
   世界重载时丢弃旧队列。主线程泵同时挂 `ServerApi.Hooks.GameUpdate` 与原版
   专用服务器主循环的 `Main.OnTickForThirdPartySoftwareOnly`（部分 TSAPI/OTAPI
   组合下前者不触发，后者是原版每刻必调，二者共用一个泵、原子出队，重复驱动无害）。

> 已知无害边缘：熔岩中水量过少的火焰花会被原版 `CheckAlch` 反复切换，插件每个
> 周期都会强制其开花，客户端看到的最终状态为开花。
# HerbBloom 全草药常开

- 作者: 不是现在
- 适用: TShock 6.x · Terraria 1.4.5.x

让所有草药（太阳花/月光草/闪光根/死亡草/水叶草/火焰花/霜花）**成熟即开花、无视昼夜/天气/月相条件，且开花后永不回退**——把原版霜花（Shiverthorn）"成熟后开花且不落"的逻辑推广到全部品种。生长速度默认保持原版。

## 行为

| 项 | 说明 |
| --- | --- |
| 开花 | 成熟草(83)立即改为开花 tile(84)，客户端对 84 无条件渲染开花、采集必掉种子 |
| 不回退 | 闪光根随机落花、熔岩火焰花水量切换等原版回退，会在巡检周期内改回开花态 |
| 生长 | 默认完全原版速度；可配置在玩家附近催熟 |
| 范围 | 陶盆/种植架与地面共用同一套 tile，自动一并生效 |

## 配置

`tshock/HerbBloom.json`（首次运行自动生成，修改后重启生效）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `启用` | `true` | 总开关 |
| `无视条件开花` | `true` | 成熟草药立即开花 |
| `开花后不回退` | `true` | 周期内改回被回退的草药 |
| `幼草直接开花` | `false` | `true` = 幼草直接开花 |
| `生长速度倍率` | `0` | `0` = 原版速度；`>0` 按 `生长基础概率 × 倍率` 催熟玩家附近幼草 |
| `扫描间隔秒` / `玩家扫描半径` / `全局扫描列数` / `每刻最大同步数` / `生长基础概率` / `详细日志` | `10` / `160` / `600` / `1500` / `0.2` / `false` | 巡检与限流参数 |

## 原理

1.4.5 草药统一为 tile `82 幼年 / 83 成熟 / 84 开花`（品种 = `frameX / 18`）。原版只有闪光根（随机开落）与霜花（成熟开花不落）在服务端改变类型，其余品种的"开花"是客户端按条件渲染的。插件把成熟草直接置为 84——客户端对 84 无任何条件判断，永远开花、永远掉种子，再由周期巡检保证不回退。
