# NoNaturalInvasion 阻止自然入侵

只拦截「凌晨自然刷出」的哥布林入侵 / 海盗入侵，避免它们随机打断发育、洗劫城镇；
手动召唤（入侵旗帜 / 海盗地图）与 `/invade` 等主动召唤完全不受影响。

## 功能
- 拦截自然触发的哥布林 / 海盗入侵（破晓时的自然判定）。
- 手动召唤不受影响：入侵旗帜、海盗地图、`/invade` 等照常。
- 三层防护：每秒检查 + MonoMod 拦 `Main.StartInvasion` + 定时兜底，漏网概率极低。
- 完全自动，无需命令与配置。

## 命令 / 配置
无。放入即生效。

## 部署
TShock 6.1.0+，把 `NoNaturalInvasion.dll` 放进 `ServerPlugins/`，重启或用插件管理器加载。
