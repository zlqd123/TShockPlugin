# AdaptiveBossHP —— TShock Boss 自适应血量插件

Boss 的血量不再是固定值：**初始按百分比增幅（X），每次失败临时减免（Y），每成功一次永久递减（线性）**。
所有数值均为**百分比**配置，对任意难度（经典/专家/大师）与世界类型均按原版血量等比缩放。
Boss 的血量阶段（如世纪之花 50% 转阶段）不受影响——插件等比缩放 life 与 lifeMax，阶段照常在相同百分比触发。
当前版本：**1.0.1**（配置文件键名全部为中文）。

## 公式

**成功衰减（永久，线性递减，默认）：**

```
成功率 = max(下限, 首战倍率 - "每次成功永久减少百分点" × 成功次数)
```

- **每成功一次，血量固定下降配置的百分点**（默认 10，即 150% → 140% → 130%…），直到下限。
- 每一场都有明确可见的变化；总衰减周期 = 加成空间 ÷ 步长（默认从 150% 到 50% 共 10 次）。

**失败减免（临时，连败累计，成功即清零恢复）：**

```
失败率 = (1 - "每次失败临时减少百分比")^当前连败次数
```

**最终：**

```
血量 = 原版 × 成功率 × 失败率        （不低于下限，默认 50%）
```

| 连败次数（Y=15%） | 血量比例 | | 累计成功次数（步长 10pp） | 血量比例 |
| :-: | :-: | :-: | :-: | :-: |
| 0（首战） | 150% | | 0（首战） | 150% |
| 1 | 127.5% | | 1 | 140% |
| 3 | 92.1% | | 5 | 100% |
| 5 | 66.6% | | 8 | 70% |
| **7** | **50%（下限）** | | **10** | **50%（下限）** |
| 20 / 50 / 100 | 50%（兜底） | | 20 / 50 / 100 | 50%（兜底） |

- **Y 是临时的**：连败减免只在"上次成功之后"累计，一旦击败立即清零恢复。
- **成功衰减是线性的**：每次成功固定降，永远有可感知的变化，到下限为止。
- **其他算法可选**（"成功衰减算法"配置项，支持中文或英文值）：
  - `"线性递减"`（默认）：如上。
  - `"半衰期"`：加成空间每"成功衰减半衰期"次成功减半，前快后慢（配 `"成功衰减半衰期"`）。
  - `"乘法衰减"`：每次成功整体乘 `(1 - "每次成功乘法衰减百分比")`（对应英文 `PercentPerWin`）。

## 判定规则

| 事件 | 判定 | 时机 |
|---|---|---|
| **成功** | 本场战斗中该 Boss 的所有关键部位（"判定击败的关键NPC的ID"）全部被击杀 | 击杀瞬间记录，全组 NPC 消失后结算 |
| **失败** | 有本组 NPC 在**未被击杀**的情况下消失（逃逸/团灭/天亮逃跑） | GameUpdate 轮询（约每 1/6 秒） |

边界情况处理：

- **多段 Boss**：毁灭者/世界吞噬怪/血肉墙等所有部位按同一比例缩放；只有关键部位（毁灭者头部、月总核心等）死亡才算成功。
- **双子魔眼**：两尊都被击杀才算成功，只杀一只后团灭 = 失败。
- **世界吞噬怪分裂**：分裂出的新头也会被自动纳入追踪并等比缩放，需全部击杀。
- **血量分阶段**：所有阶段判定基于 `life/lifeMax` 比例，等比缩放不影响触发点。
- **无人在线保护**：Boss 消失时若服务器无人（停服、最后一名玩家退出），不计成败，静默清理。
- **同一 Boss 多次召唤**：同时存在的同组 Boss 共享一场会话，需全部击杀才算成功。

## 安装

1. 需要 **TShock 6.x（Terraria 1.4.5+）**，插件基于 `.NET 9 / TSAPI 2.1` 构建。
2. 将 `AdaptiveBossHP.dll` 复制到服务器的 `ServerPlugins/` 目录。
3. 启动服务器，自动生成默认配置。

> 从旧版本升级：v1.0.1 的配置键名已全部中文化，与旧配置不兼容——请**删除** `tshock/AdaptiveBossHP.json` 与 `tshock/AdaptiveBossHP_State.json` 后重启服务器重新生成（统计数据会清零）。
> 旧版 TShock 5.2（Terraria 1.4.4，.NET 6）需将 `AdaptiveBossHP.csproj` 中 `TargetFramework` 改为 `net6.0` 后重新编译。

## 配置文件

首次运行生成 `tshock/AdaptiveBossHP.json`（键名全部中文）：

```jsonc
{
  "是否启用": true,
  "是否广播消息": true,
  "全局血量下限百分比": 50,
  "Boss组": {
    "KingSlime": {
      "显示名": "史莱姆王",
      "组内NPC的ID": [50],
      "判定击败的关键NPC的ID": [50],
      "初始血量增幅百分比": 50,          // X：首战 150%
      "每次失败临时减少百分比": 15,      // Y：每次失败 -15%，成功后恢复
      "每次成功永久减少百分点": 10,      // 线性递减步长：每次成功 -10 个百分点
      "每次成功乘法衰减百分比": 10,      // 仅"乘法衰减"模式使用
      "成功衰减算法": "线性递减",        // 线性递减 / 半衰期 / 乘法衰减
      "成功衰减半衰期": 10,              // 仅"半衰期"模式使用
      "单独血量下限百分比": null         // null=用"全局血量下限百分比"
    }
    // … 其余默认组见下方列表，键名为组标识（/bossdiff reset 用）
  }
}
```

新增/自定义组：在 `Boss组` 里加一段即可，NPC ID 对照 [Terraria Wiki: NPC IDs](https://terraria.wiki.gg/wiki/NPC_IDs)。
月度四柱（太阳/星旋/星云/星尘之柱）默认未收录，需要可自行添加。

## 状态文件

`tshock/AdaptiveBossHP_State.json`（自动生成）：

```jsonc
{
  "Boss组": {
    "KingSlime": {
      "成功次数": 2,        // 累计成功 —— 驱动永久衰减
      "当前连败次数": 1,     // 成功时清零 —— 驱动临时减免 Y
      "累计失败次数": 3      // 历史失败总数（仅统计）
    }
  }
}
```

变更即写盘，重启不丢。想手动清零直接删除文件或用指令。

## 指令（权限：`adaptivebosshp.admin`）

| 指令 | 说明 |
|---|---|
| `/bossdiff status` | 查看各 Boss 成功次数/连败次数/下次血量（含原版血量换算） |
| `/bossdiff reset <组名\|all>` | 重置统计（组名可用 `status` 里的方括号名或中文显示名） |
| `/bossdiff reload` | 重载配置（也支持 TShock 的 `/reload`） |

别名：`/bdhp`

## 默认 Boss 组

**主线 Boss**（26 组中除下列事件 Boss 外的全部）：初始 +50%、每失败 −15%、每成功 −10 个百分点。
史莱姆王、克苏鲁之眼、世界吞噬怪、克苏鲁之脑、蜂王、骷髅王、独眼巨鹿、血肉墙、史莱姆皇后、
双子魔眼、毁灭者、机械骷髅王、世纪之花、石巨人、猪龙鱼公爵、光之女皇、拜月教邪教徒、月亮领主。

**事件 / 小 Boss**（8 组）：**无初始增幅（首战即原版 100%）、无失败惩罚**，仅保留成功永久衰减（每次 −10 个百分点，5 次成功到 50% 下限），团灭也不播报失败消息。
双足翼龙、飞翔海盗船、火星飞碟、哀木、南瓜王、常绿尖叫怪、圣诞坦克、冰雪女王。

## 构建

```bash
cd AdaptiveBossHP
dotnet build -c Release
# 产物：bin/Release/AdaptiveBossHP.dll
```

依赖：.NET 9 SDK；NuGet 自动还原 `TShock 6.2.1`（含 TSAPI）。

## 已知限制

- 同组 Boss 的多个召唤物共享一场会话：同时召两只克眼需全杀才算成功。
- Boss 被管理指令（如 `/butcher`）杀死同样计为"成功"。
- 四柱默认不收录（它们没有"逃逸失败"的概念）。
